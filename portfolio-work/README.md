# Портфолио Евгении Вишневской

Рабочий стартовый проект на **Next.js + TypeScript** для собственного домена и VPS. Исходные макеты: [Figma](https://www.figma.com/design/i9c2fy2jQaZ9JWCOzVYsyr/?node-id=1581-11412).

## Локальный запуск

Требуется Node.js 20.9+.

```bash
npm install
npm run dev
```

Открыть `http://localhost:3000`.

## Замена контента и изображений

Данные карточек, названия, описание, статус и ссылки: `lib/projects.ts`.

**ВАЖНО:** Визуализации в `components/Visual.tsx` — честные CSS-заглушки, а не экспортированные экраны из Figma. Для визуального соответствия макетам необходимо экспортировать оригинальные иллюстрации из Figma и заменить компоненты-превью на локальные файлы из `public/`. Портрет в главном блоке также временный. Вызовы Figma MCP исчерпали лимит тарифного плана, поэтому изображения пока не загружены. Не публикуйте как финальную версию без этого этапа.

Ссылка «Запросить CV» пока ведёт в Telegram; нужно добавить файл резюме или отдельную форму. Английский язык пока не реализован: RU — индикатор текущего языка, не переключатель.

## Деплой на VPS

Подход: Node.js + reverse proxy (Caddy или Nginx) + HTTPS.

```bash
npm install
npm run build
npm run start
```

Для постоянной работы процесса используйте `systemd` или Docker, если нужно. После привязки A/AAAA-записи домена к VPS настройте reverse proxy на `localhost:3000`, включите HTTPS и автообновление сертификата. **Не открывайте порт 3000 публично**.
