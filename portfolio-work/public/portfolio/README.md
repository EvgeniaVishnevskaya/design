# Portfolio assets

Place exported Figma frames here and register their public paths in
`lib/portfolio-assets.ts`. Prefer WebP or AVIF for raster screens and SVG for
vector artwork. Large case-study frames preserve their source aspect ratio.

Suggested names: `portrait.webp`, `report-designer.webp`, `tfsix.webp`,
`idm.webp`, `softlogic.webp`, `smart-city.webp`, `reporting.webp`, and
`softlogic-{face-recognition,camera-management,video-analytics,report-builder,user-profile}.webp`.
